# Structure Builder for Web Projects

## Description
This project is a CLI that helps generate the initial structure of a project.

## Table of Contents
- [Simple web command](#simple-web-command)

## Simple Web Command
This command will create a structure for a simple website, receiving the following arguments: 

- `-sw or --simpleWeb`: 
This command is used to generate the structure of a simple web project.
- `-p or --path`:
Use this command to specify the path where you want to create the project structure.
- `-n or --name`:
Use this command to specify the name of the project.
